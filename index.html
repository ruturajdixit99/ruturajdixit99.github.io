03 / Selected work

Things I've built.

Demo · Robotics
Pace AI & Robotics Lab · ADAPT

"Go to the chair." Object-goal navigation on a Clearpath Jackal

  1. Type an object name. Detection locks onto that single target, and the operator can click to choose between several.
  2. ZED stereo depth measures the distance, and the robot drives up and stops 0.75 m away.
  3. VGGT rebuilds the scene in 3D from 4 views, rendered live in Open3D.
  4. LiDAR and ZED run independent safety checks. If data goes stale or the target is lost, the robot holds instead of guessing.
